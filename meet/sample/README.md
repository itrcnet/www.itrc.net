# 編集用サンプル（非公開）

`meet/sample/` は第60回研究会を元にしたMarkdownの書式サンプルです。`_config.yml` の `exclude` により、`meet/sample/` 以下はHTML生成・公開の対象外です。GitHub上では参照できます。

- `index.md`：開催回の入口と自動一覧
- `cfp.md`：開催概要、表、リンク、取り消し線
- `cfp-demo.md`：デモ展示募集
- `program.md`：プログラム、発表概要

申込フォームのURLは `https://example.org/registration` に置き換えています。実際の申込先ではありません。

新規開催回に使うときは必要なファイルを `meet/<開催回>/` にコピーし、タイトル・開催回・`listing_order`・`permalink`・日程・会場・料金・連絡先・リンクを更新してください。受付終了の注記や取り消し線も新しい募集状況に合わせて編集します。サンプルの公開パスは第60回のままなので、`permalink` を必ず変更してください。
